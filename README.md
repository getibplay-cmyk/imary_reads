# Imary Reads · إيماري ريدز

منصة قراءة ونشر مبنية على **Laravel 13 وPHP 8.3+**، بواجهة عربية افتراضية تدعم الفرنسية والإنجليزية. التصميم مستوحى من النموذج المرجعي: كحلي ليلي، بنفسجي وذهبي، عمارة مغربية، مكتبة أغلفة، واستوديو للكاتب وقارئ على هيئة كتاب.

**حالة التسليم:** شيفرة قابلة للتشغيل، ترحيلات قاعدة البيانات، اختبارات، أصول أصلية، وإعداد تشغيل بالحاويات. جرى فحص صفحات مولدة من Laravel بصريًا في المتصفح وتجربة قارئ الكتاب؛ لم يُنشر موقع عام ولم تُختبر دورة التشغيل الإنتاجية كاملة. راجع [تقرير التحقق](docs/VALIDATION.md) قبل الإطلاق.

## ما يعمل

- العربية RTL افتراضيًا، الفرنسية والإنجليزية LTR؛ لغة نص الرواية مستقلة عن لغة الواجهة، وتفضيل اللغة محفوظ في الجلسة والحساب. رسائل التحقق والاستعادة مترجمة.
- مكتبة بترشيح اللغة والتصنيف والنوع والحالة والترتيب؛ بحث فوري في العناوين وأسماء المؤلفين، مع اقتراحات لوحة المفاتيح وإلغاء الطلبات القديمة.
- صفحات الأعمال والمؤلفين والتصنيفات والمدونة؛ ظهور المحتوى المنشور والمتاح فقط.
- القراءة بالتمرير أو بكتاب متقلب الصفحات: نص حقيقي، اتجاه عربي، صفحات ورقية، ظل وثنية، صورة افتتاحية على الصفحة المقابلة، إعادة تقسيم عند تغيير الخط أو العرض، وأوضاع ورق/نهار/ليل.
- حسابات، تأكيد البريد، استعادة كلمة المرور، تأكيد كلمة المرور للإجراءات الحساسة، تحقق بخطوتين ورموز استرداد. لا توجد حسابات إدارية أو كلمات مرور افتراضية.
- تعليقات وردود بمستوى واحد، تقييم واحد قابل للتحديث لكل قارئ، مفضلة، متابعة المؤلفين، رفوف خاصة، علامات قراءة، تقدم قراءة، بلاغات وإشعارات الفصول الجديدة.
- استوديو الكاتب: أعمال وأغلفة وحقوق نشر، فصول ومحرر غني وحفظ تلقائي، كشف تعارض التحرير، إصدارات واستعادة، جدولة، ترتيب وحذف الفصول، أرشفة الأعمال واسترجاعها كمسودات، إدارة الملفات والتعليقات والمتابعين.
- رفع PDF/EPUB/TXT حتى 20 MB؛ ملفات خاصة محجوزة حتى نجاح فحص ClamAV. استيراد النص من EPUB/TXT، وتنزيل TXT/EPUB أو الملف الأصلي عندما يسمح الكاتب. تعطيل التنزيل يسري على الطلب التالي.
- إدارة: مراجعة النشر، البلاغات، الحسابات والأدوار والحظر، التصنيفات المترجمة، مؤلفون مستقلون عن حسابات المستخدمين، المدونة، إعادة فحص الملفات، الإعلانات وسجل العمليات.
- تصدير بيانات الحساب وحذفه مع سحب أعماله من الجمهور وإبطال جلساته.

## التشغيل المحلي

المتطلبات: PHP 8.3 أو أحدث، Composer 2، Node.js 22.12+، وامتدادات `mbstring intl dom xml curl fileinfo gd zip pdo_sqlite`، و`pdo_pgsql` عند استخدام PostgreSQL. يلزم ClamAV بتواقيع محدثة لفك حجز الملفات المرفوعة.

```bash
composer setup
php artisan db:seed --class=DemoSeeder
php artisan serve
```

افتح `http://localhost:8000`. سكربت الإعداد ينشئ `.env` وقاعدة SQLite محلية عند غيابهما، ولا يبدل مفتاح تطبيق موجود. **لا تشغله لتحديث إنتاج قائم**؛ اتبع دليل النشر والترقية.

في نافذتين إضافيتين:

```bash
php artisan queue:work --tries=3 --timeout=120
php artisan schedule:work
```

أعد `npm run build` بعد تعديل الواجهة. `npm run dev` يشغل Vite، لكن سياسة CSP الافتراضية مُعدة للأصول المبنية من المصدر نفسه؛ استخدم البناء أثناء التطوير إذا لم تُضبط سياسة HMR محليًا.

`DatabaseSeeder` يضيف التصنيفات فقط. `DemoSeeder` اختياري للتطوير، يضيف ست قصص افتتاحية أصلية توضيحية ومقالًا، ويرفض العمل في بيئة الإنتاج. هذه النصوص ليست مكتبة روايات منشورة أو روايات كاملة؛ لا يضيف التوليد مشاهدات أو تقييمات وهمية.

البريد المحلي يُكتب في سجل التطبيق (`MAIL_MAILER=log`). اضبط SMTP لتصل رسائل التحقق والاستعادة فعليًا. لا تستخدم عنوان شخص آخر لإنشاء حساب تجريبي.

إنشاء المشرف الأول، بكلمة مرور تُدخلها أنت سرًا:

```bash
php artisan imary:admin you@example.com
```

ثم فعّل التحقق بخطوتين من صفحة الأمان. إدارة الإنتاج تتطلب التحقق بخطوتين وتأكيد كلمة المرور.

## نطاق دعم الملفات

قارئ الكتاب يعمل على الفصول النصية؛ الملفات المستوردة تُنقى وتصبح مسودات قبل النشر. استيراد TXT يتطلب UTF-8 حتى لا تتلف الحروف. استيراد EPUB نصي، لا يحافظ على كل تنسيقات الناشر أو الصور والوسائط الخارجية. PDF مرفق قابل للتنزيل بعد الفحص، وليس قارئ PDF داخل المتصفح أو OCR. اختيار عدم السماح بالتنزيل لا يمنع نسخ نص يظهر للقارئ؛ لا يوجد ادعاء DRM.

تصدير EPUB يحوي الفصول المنشورة فقط، باتجاه عربي عند الحاجة. النص الأصلي الكامل محفوظ في قاعدة البيانات، وتغيير حجم الصفحة لا يغير الفصل. الانتقال بين العرض الكتابي والتمرير يحافظ على موضع تقريبي؛ الموضع في الكتاب محسوب بنقاط Unicode.

## GitHub

المستودع المستهدف: `getibplay-cmyk/imary_reads`. تكامل GitHub أعاد `403 Resource not accessible by integration` عند محاولة الكتابة، لذلك لا تعتبر وجود المستودع دليلًا على رفع هذه الملفات. يمكن دفع الالتزام المحلي بعد منح التكامل صلاحية Contents: read/write، أو من طرف صاحب الحساب عبر Git.

```bash
git remote -v
git push -u origin main
```

إذا بدأت من حزمة ZIP، فهي تحتوي المصدر دون مجلد `.git`. افتح الطرفية داخل `imary_reads` وابدأ تاريخًا محليًا قبل الدفع إلى المستودع الفارغ:

```bash
git init -b main
git add .
git commit -m "Build Imary Reads platform"
git remote add origin https://github.com/getibplay-cmyk/imary_reads.git
git push -u origin main
```

لا تُضمّن `.env` أو قواعد البيانات أو الملفات الخاصة أو مفاتيح التطبيق في Git. راجع الفروقات قبل دفعها إلى مستودع موجود ذي محتوى.
